🖥️ KOC-Inventory (Frontend)
This is the client-side application for the KOC-Inventory system. It provides a highly responsive, single-page interface (SPA) for managing sales, tracking stock levels, and viewing business analytics.

⚡ Key Technical Implementations
State Management: Utilizes Redux Toolkit (RTK Query) for efficient API caching and synchronization with the backend.

Form Validation: Integrated Zod with React Hook Form for strict type-safety and real-time user feedback.

UI Components: Built using Shadcn UI and Tailwind CSS for a clean, professional "Enterprise-grade" aesthetic.

Dynamic Reporting: Real-time data visualization for inventory statistics and sales trends.
